# pinsay-cli → @pinsay/cli

`pinsay-cli` is now **`@pinsay/cli`**. This package only runs `@pinsay/cli`, so `npx pinsay-cli <command>` keeps
working, but new releases and the changelog are on `@pinsay/cli`:

    npx @pinsay/cli init

For a global `pinsay` command: `npm i -g @pinsay/cli` (and `npm rm -g pinsay-cli`).

Docs: https://pinsay.dev/docs/
